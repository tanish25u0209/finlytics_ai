# Finlytics AI

AI-powered loan scoring project workspace for a 4-member team.

## Problem

Traditional loan screening can be slow, inconsistent, and hard to scale. Teams need a system that can collect applicant data, process it reliably, and generate a risk assessment that supports better lending decisions.

## Solution

Finlytics AI combines a frontend dashboard, backend APIs, and an ML risk model into one workflow so loan data can be submitted, evaluated, and reviewed in a structured way.

## Features

- User login and authentication
- Loan application data submission
- Risk scoring with an ML model
- Dashboard for application and score review
- Integrated end-to-end testing flow

## Tech Stack

- Frontend: to be decided by frontend owner
- Backend: to be decided by backend owner
- ML: Python-based model pipeline
- Testing: integration and manual validation
- Version Control: Git + GitHub

## Team Roles

- Member 1: Backend
- Member 2: Frontend
- Member 3: ML
- Member 4: Integration + Testing
